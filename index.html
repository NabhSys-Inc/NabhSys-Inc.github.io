Engineered for Technical Sovereignty
[VERIFIED]

NAR Autonomous AI Router

Host control engine running local Ollama model routing over SSH for hands-free VM operation, real-time GUI automation, and self-healing error resolution.

[PROTOTYPE]

NCE Container Subsystem

Native Compatibility Engine providing containerized Windows PE translation (`.exe`, `.msi`), prefix isolation under `/var/lib/navyom/`, and direct MIME file handler locking.

[PROTOTYPE]

Aero X Control Center

Flat, geometric PyQt6 macOS-style system settings interface operating directly on live system interfaces (`xrandr`, `systemctl`, `df`, `zramctl`) with zero fake placeholders.

[VISION]

USB Hardware Auth Vault

Physical security keys integrating `pam_u2f` hardware triggers with Btrfs read-only encrypted subvolumes for instant hardware locking and hidden local application vaults.

[VERIFIED]

Zero-Wineglass Integration

Multi-stage binary resource extraction (`wrestool` → `7z` → `icotool`) extracting authentic developer icons directly into system theme caches, blocking default wineglass icon pollution.

[VERIFIED]

Btrfs + ZRAM Storage Stack

Automated copy-on-write snapshotting backed by active `/dev/zram0` RAM compression, protecting the core OS against upgrade breakages and instant rollback capabilities.
